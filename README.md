# Spaces

[![No AI](https://custom-icon-badges.demolab.com/badge/No%20AI-2f2f2f?logo=non-ai&logoColor=white&logoSize=auto)](#)

A shared space where all can come together, like a digital third-place.

Live at [austinweeks.dev](https://austinweeks.dev/spaces/).

## Running

### Install

```sh
git clone https://github.com/austin-weeks/spaces.git
cd spaces
```

### Run Backend

Requires Rust / cargo.

```sh
cd spaces-backend
cargo run
```

### Run Frontend

Requires node / pnpm.

```sh
cd spaces-frontend
pnpm i
pnpm dev
```

Open dev URL (usually `http://localhost:5173`).
